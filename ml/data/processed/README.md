# Processed data

Generated by `python -m ml.preprocessing`. Nothing here is tracked in git —
every file is reproducible from the source dataset.

## Contents

| File | Produced by | Description |
| --- | --- | --- |
| `traffic_processed.csv` | `save_processed_data` | Model-ready rows: `road_segment_id`, `timestamp`, features…, `congestion_level` (target last) |
| `traffic_processed.csv.meta.json` | `save_processed_data` | Provenance, validation, cleaning, feature list, target mapping and recommended split |

Both are overwritten on every run. The `.meta.json` sidecar is the authoritative
record of what the pipeline did; read it before trusting the CSV.

```jsonc
                        "2": "heavy", "3": "severe" },
  "recommended_split": { "strategy": "chronological", "boundary": "..." }

```

## Checks worth doing before trusting the output

- `source.kind` — is this real data or the simulated fixture?
- `validation.errors` — must be empty.
- `cleaning.rows_dropped` — a large drop means rows were discarded.
- `cleaning.imputed_*` — heavy imputation means the source data is thin.
- `recommended_split.strategy` — must be `chronological`, never a random split.
