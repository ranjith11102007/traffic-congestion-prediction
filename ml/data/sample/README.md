"""Simulated development data.

Everything in this directory is **synthetic**. It is generated by
`generate_simulated_dataset.py` from a parametric demand model, not measured from
any road, and it is not a live data feed.

It exists for one reason: the preprocessing pipeline needs a file to run against,
and a generated fixture with a fixed seed is preferable to a hand-written CSV
that drifts from the code reading it.

**Do not report any metric derived from this data.** It demonstrates that the
pipeline works. It says nothing about real traffic behaviour, and a model trained
on it has no validity.

## Provenance is machine-checked

`SIMULATED_traffic_observations.csv.provenance.json` marks the file as simulated,
and `ml.preprocessing.detect_provenance()` reads that sidecar. The pipeline
therefore reports `kind="simulated"` from a machine-readable source rather than
from a guess about the filename, and the console report opens with a
`!! SIMULATED DATA !!` banner.

## Real data goes in `ml/data/raw/`

See `ml/data/raw/README.md` for the required schema and the accepted public
sources.

## Regenerating

```bash
python -m ml.data.sample.generate_simulated_dataset
```

Fixed seed, so the output is byte-for-byte reproducible. `--defects` injects
missing values, impossible readings and duplicates for testing the validation and
cleaning stages; it is never used for the committed fixture.
