AI-Based Urban Traffic Congestion Prediction System

A modular system that ingests real urban traffic observations, trains machine-learning models to classify congestion levels, and serves short-horizon congestion forecasts through an API and an interactive map dashboard.

Open dashboard View implementation status

Problem statement

Urban road networks routinely experience congestion that commuters only discover once they are already inside it. Reactive control reacts to congestion after it has formed, and static timetables cannot account for day-to-day variation caused by incidents, weather, construction and peak-hour shifts. The result is measurable lost time, fuel waste and avoidable emissions.

This project builds a prediction layer that estimates congestion for a road segment ahead of time, so that routing guidance and signal-timing decisions can be made before congestion builds up.

Objective

  • Real data only

    Every metric in this project comes from a real, cited dataset or a live data source. No synthetic or fabricated traffic values are used to make results look better than they are.

  • Modular ML layer

    Preprocessing, training, evaluation and inference live in an independent package that never imports the web layer, so alternative models can be benchmarked on the same footing.

  • Testable in isolation

    Each component has an automated test suite, so a change to the API, the database layer or the ML pipeline can be verified on its own.

About the project

      

        The system is delivered in stages, each independently testable and each stopping
        short of claiming results it has not earned. Stages 1 to 7 are built: the data
        pipeline, model training, the prediction API, live TomTom and Open-Meteo
        collection, the real-time prediction engine, and this dashboard.
      

      

        The model was trained on a clearly labelled simulated dataset, so its forecasts
        demonstrate the pipeline rather than real-world accuracy. The dashboard states
        that wherever a forecast is shown.
      

      

        Full setup instructions, the architecture overview and the stage roadmap are in
        README.md; deeper design notes are in docs/.
